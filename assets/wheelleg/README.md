# 当前 CAD 轮腿模型

当前活动模型来自用户提供的 `wheelleg-cad-urdf-272g-battery.zip`，导入日期为 2026-11-25。`model_info.json` 记录源压缩包 SHA256 和导入文件清单。原 IsaacLab USD 不再是本工程运行时的模型来源。

模型包含 11 个刚体、10 个树关节和两个额外闭环连接。视觉网格与碰撞网格分别存放；机身采用六块碰撞网格。运行时仍使用 Isaac Gym 的弹簧阻尼闭环近似。

| 参数 | 当前值 |
| --- | --- |
| 上连杆 | 50 mm |
| 下连杆 | 105 mm |
| 髋间距 | 约 60.0195 mm |
| 轮半径 / 宽度 | 32.5 / 28 mm |
| 轮距 | 约 218.745 mm |
| 有效腿长命令范围 | 80–130 mm |
| URDF 总质量 | 约 1.4538 kg |

**采用新压缩包提供的质量、质心和惯量，尚未独立实测标定。** 电池已包含在导出的机身模型中；机身质心 x = −3.504 mm（x 正向为前），不再沿用旧模型的 5.84 kg 参考质量。 当前模型不代表这些动力学参数已经与实机一致。STM32 工程中的旧轮半径也需在以后部署时重新核对。

`loop_constraints.json` 是闭环锚点、主动/被动关节顺序及 CAD 尺寸的共同来源；`legged_gym/envs/wheelleg/model/geometry.py` 统一提供运动学、传感器状态计算及控制器使用的尺寸。为配合新连杆惯量，已移除旧模型的 0.05 kg·m² 人工关节惯量，基础任务默认髋关节阻尼为 0.2 N·m·s/rad；本次传感器站立任务对轻量化模型使用 Kp=2.0、Kd=0.04；这只是导入后的数值适配，仍需训练和平衡验收。右轮在 URDF 树上连接 `R_H_Link2`，额外闭环连接 `R_F_Link2`；不能套用旧模型的右侧父子关系。

旧资产完整备份于本机 `logs/model_backup_20261125/old_wheelleg/`，旧精选权重已移除，可在 Git 历史中追溯。新保存的检查点包含模型指纹，加载时必须匹配；旧权重不能作为新模型已经训练完成的结果。

在 IsaacGym 目录执行：

```bash
./manage.sh run tools/check_model.py --report validation/cad_model_check.json
./manage.sh preview --length 0.10
./manage.sh preview --headless --sim-device cuda:0 --num-envs 16 --steps 300
```

预览默认固定机身，用于检查机构；`--free-base` 取消固定。预览不加载策略，不代表机器人已经能站稳。`--steps` 按 50 Hz 控制步计数。

旧 USD 导出工具已移除。更新当前 CAD 模型时，应同时更新 URDF、网格、闭环元数据及文件指纹清单，再重新检查并训练。

## 电机输出力矩

当前电机参数在 `loop_constraints.json::actuator_limits`，单位按减速后的输出端 N·m 处理。髋峰值 0.68、连续 0.32，峰值允许 2 秒；每个轮子峰值 0.1 N·m，轮电机连续值和转速曲线尚未提供。

仿真在 PD、支撑前馈、RL 残差合成后逐关节限幅。髋关节各自累计超过连续力矩的物理步数，累计 2 秒后降到 0.32，直到回合重置；没有假设冷却恢复速度。真实电机还需校准热模型和转速-力矩曲线。预算尚未加入策略观测，部署时也必须在 MCU 端执行对应限流/降额。

当前每腿支撑前馈按 URDF 总质量扣除两轮质量后计算，为约 6.483 N；髋部力矩由当前姿态的雅可比换算。更新 URDF 质量后会自动更新前馈，不能据此替代站稳验证。

安静站立诊断还测试了 Kd=0.005；目前仅保留在候选任务 `wheelleg_sensor_quiet`，未替代基础任务，候选策略尚未通过安静站立验收。
