# 先站稳，再左右交替抬轮

这个入口练习原地换重心和短暂单轮支撑。现有 RL 负责轮子前后平衡，显式控制器安排左右腿目标、支撑前馈、阻抗和落轮恢复；没有新增 PPO 训练，也尚未实现向前迈步。

## 运行

本机：

```bash
conda activate isaacgym
cd /home/gary/wheelleg_work/WheelLeg_RL_IsaacLab-main/IsaacGym
./lift.sh
```

公司电脑进入克隆的 `wheelleg-isaacgym` 目录后运行同一个 `./lift.sh`。环境安装见 [公司电脑指南](COMPANY_SETUP.md)。

启动后先保持双轮站立，**默认等待键盘，不会自己开始抬轮**。先点击 Isaac Gym 仿真窗口让它获得焦点，在窗口中按键，不是在终端中输入：

| 按键 | 动作 |
| --- | --- |
| N | 请求下一侧抬轮，首次左轮、下次右轮；仍须通过站稳和换重心检查 |
| 空格 | 开启连续交替 / 请求落稳后暂停 |
| 关闭窗口 | 结束演示并保存当前报告 |

按住 N 不会重复触发；动作进行中按 N 不排队。暂停不会冻结机器人或让悬空的轮子停住，会先完成当前轮的落地与站立恢复。键盘模式默认运行 300 仿真秒，可以反复请求抬轮，不受三组次数限制；`--seconds 600` 可增加本次时长。暂停时双轮平衡继续运行。没有给这个入口接方向键驾驶和 Q/E 调腿长；这些仍在 `./stand.sh` 中使用。

原来的自动三组演示使用：

```bash
./lift.sh --auto
```

自动模式先双轮站立至少 3 秒，确认稳定后缓慢向支撑侧倾斜，再收起另一侧腿；落轮、回正、连续稳定至少 0.8 秒后才允许换边。默认左右各 3 次，约 21 秒完成动作，之后继续双轮站立，到 60 仿真秒结束。键盘模式也保留这些稳定门槛。

无窗口复测及保存每步测量：

```bash
./lift.sh --headless --report validation/my_lift.json --record-trace
```

默认名义腿长 10 cm。已经小范围复测 9.8、10、10.2 cm；例如 `./lift.sh --length 0.102`。这不代表 6～20 cm 全范围都能抬轮。`./run.sh lift.py --help` 可查参数；直接运行 Python 入口时需要显式传检查点与模式，推荐从 `lift.sh` 开始。

## 做了什么

- 左右腿可以分别指定长度和支撑力，沿用五连杆逆解与雅可比支撑前馈。髋关节仍通过实际力矩驱动，最终受原有力矩限制。
- 双轮稳定、预倾、收腿、落轮、回正、恢复分别有状态和检测条件。俯仰超过约 6.9°或横滚超过约 12.6°时中止本次抬轮并逐渐落轮；等待稳定超时就停止继续换边。
- 抬轮时提高摆动腿位置刚度，落轮时提高阻尼；在两腿之间重新分配原有总支撑前馈，没有给机身增加外部支撑力。
- 沿用 `standing_hold.pt` 的轮子网络权重。抬轮入口显式使用 `sagittal` 输入适配：左右腿相关特征取平均，屏蔽轮子平衡网络不适用的侧倾特征。真实姿态、接触与安全检查仍使用完整物理状态。
- 通过轮子策略发送最多 ±0.04 m/s 的小幅位置修正，减少连续抬轮的前后偏移。用户目标速度为零，但内部修正指令不恒为零，报告中有记录。

## 胎面碰撞模型

`lift.sh` 显式选择 `--wheel-collision sphere_tread`。原始轮胎外圈顶点位于半径 62.5 mm、轴向中心 -22 mm 的球面带上。抬轮模式把这两个轮子的碰撞形状换成连续球面，以避免原网格接触切换影响小速度平衡；视觉、质量、质心、惯量和关节坐标不变。

这个代理只在平地、接触点位于原球面带范围内时适用，几何范围约为轮轴倾斜不超过 18.66°。完整球面伸出了原胎面带边缘，因此不能把它当作所有角度和地形下完全相同的原碰撞模型。报告检查实际轮轴倾角是否超出范围；本次峰值约 7.1°。原有 `stand.sh`、训练和资产文件仍使用原碰撞配置。

可用 `./lift.sh --auto --wheel-collision mesh` 复测原网格。相同控制器在本机原网格对照中仅完成一组后等待稳定超时，未通过三组验收。因此目前通过的结果依赖上述胎面代理与输入适配。

没有固定机身、减小重力或在控制中写入根位置/速度。五连杆连接仍是原工程的弹簧阻尼近似闭环，不是原生刚性闭环。

## 怎样判定真的抬轮

主动抬轮阶段必须同时满足：

1. 摆动轮与地面的几何间隙至少 3 mm。
2. 整个 20 ms 控制周期内，所有物理子步的摆动轮接触力范数均小于 1 N。
3. 另一轮平均垂直接触力大于 5 N，且机身和其他连杆没有接触地面。
4. 连续满足至少 40 ms；落轮后的反弹不计入成功抬轮。

每次还需落轮后通过稳定门槛。整轮评估需要左右各 3 次成功、零倒地重置、零非轮接触、平面最大位移不超过 3 cm，完成后连续稳定至少 2 秒；提前关闭窗口不会得到完整协议通过的结论。

这是短暂动态单轮支撑，尚未证明持续单轮站立、抗推扰、复杂地面、长期原地保持或向前步行。下一步应先延长可靠的支撑时间，再加入小幅摆腿落点和前进目标。
